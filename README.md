# CFB Standings Engine 🏈

A simple React web application to simulate the college football season, view conference standings, and generate the 12-team College Football Playoff bracket.
Access the live application at: collegefootballstandings.me

## Features
* **Season Simulation:** Pick winners manually or use the simulation engine to generate results.
* **Interactive Standings:** Tracks conference and overall records automatically.
* **Postseason Bracket:** Generates the 12-team CFP bracket and winter bowl game matchups based on regular-season results.
* **Save/Load:** Export your season data to save your progress or share it with others.
* **History:** Explore the past of your favorite teams.

## How to Run Locally
Make sure you have Node.js installed, then run the following commands in your terminal:

1. Install the dependencies:
npm install

2. Start the development server:
npm run dev

3. Open http://localhost:5173 in your browser.
